# FixtureForge

FixtureForge is a paid plugin for JetBrains IDEs. It reads a JSON Schema and writes reproducible **valid and invalid**
JSON test fixtures, a manifest that gives the expected validity and reason for every file, and a constraint-coverage
report.

This repository holds the plugin's licence and its public issue tracker. The source code is not public.
